# removeDuplicatesandSpaces ✂️

## 📌 Overview
Removes duplicate characters and unnecessary spaces from a string to produce a clean output.

---

## 🎯 Features
- Eliminates duplicate characters
- Removes extra spaces
- Preserves order (if implemented)

---

## 🧠 Concepts Used
- Sets / Hashing
- String processing

---

## ⚙️ Workflow
1. Traverse string
2. Track seen characters
3. Build new string without duplicates/spaces

---

## ⏱ Complexity
- Time: O(n)
- Space: O(n)
