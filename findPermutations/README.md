# findPermutations 🔀

## 📌 Overview
Generates all possible permutations of a given string or set.

---

## 🎯 Features
- Recursive permutation generation
- Supports multiple inputs

---

## 🧠 Concepts Used
- Recursion
- Backtracking

---

## ⚙️ Workflow
1. Fix one element
2. Recursively generate permutations for remaining elements
3. Combine results

---

## ⏱ Complexity
- Time: O(n!)
- Space: O(n!)

---

## 📍 Learning Outcome
- Understanding recursion deeply
- Backtracking algorithms

---

## 🚀 Resume Value
⭐ VERY HIGH — Classic DSA problem
