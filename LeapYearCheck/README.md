# LeapYearCheck 📅

## 📌 Overview
Checks whether a given year is a leap year based on standard calendar rules.

---

## 🎯 Features
- Validates leap year logic
- Supports multiple inputs

---

## 🧠 Concepts Used
- Conditional statements
- Logical operators

---

## ⚙️ Workflow
- Year divisible by 4 → Leap year  
- Except divisible by 100 → Not leap  
- Except divisible by 400 → Leap  

---

## 📍 Learning Outcome
- Applying real-world rules in code
