# FirstNonRepeatingChar 🔍

## 📌 Overview
Finds the first character in a string that does not repeat.

---

## 🎯 Features
- Efficient lookup
- Maintains order

---

## 🧠 Concepts Used
- HashMap (dictionary)
- String traversal

---

## ⚙️ Workflow
1. Count frequency of characters
2. Traverse string
3. Return first unique character

---

## 📍 Learning Outcome
- Optimized searching (O(n))
