# moveSpecialCharacters 🔀

## 📌 Overview
Rearranges a string by moving special characters to a specific position (start/end) while preserving order of other characters.

---

## 🎯 Features
- Separates alphanumeric and special characters
- Maintains relative ordering

---

## 🧠 Concepts Used
- String traversal
- Character classification

---

## ⚙️ Workflow
1. Iterate through string
2. Separate special and normal characters
3. Concatenate based on requirement

---

## ⏱ Complexity
- Time: O(n)
- Space: O(n)

---

## 📍 Learning Outcome
- String manipulation techniques
- Stable transformations
