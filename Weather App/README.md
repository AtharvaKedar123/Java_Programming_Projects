# Weather App 🌦

## 📌 Overview
A weather application that fetches and displays real-time weather data based on user input.

---

## 🎯 Features
- Search weather by city
- Display temperature, conditions, etc.
- Real-time data fetching

---

## 🧱 Architecture
- Input → City name
- API Layer → Weather API (e.g., OpenWeather)
- Output → Weather details

---

## 🧠 Concepts Used
- API integration
- JSON parsing
- HTTP requests

---

## ⚙️ Workflow
1. User enters city name
2. Send request to weather API
3. Parse JSON response
4. Display weather details

---

## 📍 Learning Outcome
- Working with APIs
- Handling real-time data
