# LCMProgram ➕

## 📌 Overview
Calculates Least Common Multiple (LCM) of two or more numbers.

---

## 🎯 Features
- Multiple number support
- Efficient computation

---

## 🧠 Concepts Used
- GCD/LCM relationship
- Arithmetic logic

---

## ⚙️ Workflow
- Use formula:
  LCM(a, b) = (a * b) / GCD(a, b)

---

## 📍 Learning Outcome
- Mathematical problem solving
