# SumCheck ➕

## 📌 Overview
Checks whether a given sum condition is satisfied within a dataset (e.g., two numbers adding up to a target).

---

## 🎯 Features
- Target sum validation
- Efficient lookup

---

## 🧠 Concepts Used
- HashSet / dictionary
- Iteration

---

## ⚙️ Workflow
1. Iterate through elements
2. Check if complement exists
3. Return result

---

## 📍 Learning Outcome
- Understanding optimized searching (O(n))

---

## 🚀 Resume Value
⭐ HIGH — Classic interview problem (Two Sum concept)
