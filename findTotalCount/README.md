# findTotalCount 🔢

## 📌 Overview
Counts total number of elements or occurrences within a dataset.

---

## 🎯 Features
- Counts elements efficiently
- Works with arrays or lists

---

## 🧠 Concepts Used
- Iteration
- Counters

---

## ⚙️ Workflow
1. Traverse dataset
2. Increment counter
3. Return total count

---

## ⏱ Complexity
- Time: O(n)

---

## 📍 Learning Outcome
- Basic aggregation logic
