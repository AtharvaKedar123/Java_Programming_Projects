# findHighestOccurrence 📊

## 📌 Overview
Identifies the element with the highest frequency in a dataset.

---

## 🎯 Features
- Counts occurrences of elements
- Returns most frequent value
- Handles duplicate-heavy datasets

---

## 🧠 Concepts Used
- HashMap / Dictionary
- Frequency counting

---

## ⚙️ Workflow
1. Traverse dataset
2. Store counts in dictionary
3. Track maximum frequency
4. Return element with highest occurrence

---

## ⏱ Complexity
- Time: O(n)
- Space: O(n)

---

## 📍 Learning Outcome
- Efficient counting techniques
- Using hash-based lookups
