# Factorial 🔢

## 📌 Overview
Computes the factorial of a given number using iterative or recursive approaches.

---

## 🎯 Features
- Supports large inputs (depending on implementation)
- Iterative and/or recursive solution

---

## 🧠 Concepts Used
- Recursion
- Loops
- Mathematical computation

---

## ⚙️ Workflow
1. Take input number `n`
2. Compute `n * (n-1) * ... * 1`
3. Return result

---

## 📍 Learning Outcome
- Understanding recursion vs iteration
- Base case handling
