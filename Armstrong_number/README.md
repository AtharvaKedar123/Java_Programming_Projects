# Armstrong_number 🔢

## 📌 Overview
A program that checks whether a given number is an Armstrong number (a number equal to the sum of its digits raised to the power of the number of digits).

---

## 🎯 Features
- Accepts user input
- Calculates digit powers
- Validates Armstrong condition

---

## 🧠 Concepts Used
- Loops
- Mathematical operations
- Number manipulation

---

## ⚙️ Workflow
1. Take input number
2. Count number of digits
3. Compute sum of digits raised to power
4. Compare with original number

---

## 📍 Learning Outcome
- Understanding number-based algorithms
- Practicing mathematical logic
